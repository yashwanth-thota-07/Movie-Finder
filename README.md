# 🎬 MovieFinder

MovieFinder is a React-based movie search application powered by the OMDb API. Users can search for movies, browse posters, and view release years through a modern dark-themed interface.

## 🌐 Live Demo

https://movie-finder-neon-psi.vercel.app/

## 🚀 Features

- Search movies by title
- View movie posters
- Display release years
- Responsive card layout
- Dark-themed UI
- Powered by OMDb API

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Vite
- OMDb API
